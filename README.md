# WorstYoutubeDownloader - it can download a lot more actually

how to (if you really need to):
- install ffmpeg (https://ffmpeg.org/) and make sure it is on your PATH
- install the .NET 10 SDK (https://dotnet.microsoft.com/download) - Windows only, it's a WPF app
- compile and run the project: `dotnet run --project src/BestYoutubeDownloader`

yt-dlp is downloaded next to the app and updated automatically on startup.

using yt-dlp: https://github.com/yt-dlp/yt-dlp

check this for supported sites: https://github.com/yt-dlp/yt-dlp/blob/master/supportedsites.md
